# Политика безопасности

## Что делает скрипт с вашей системой

Чтобы решения были осознанными, перечислим побочные эффекты полностью:

| Действие | Область |
| :--- | :--- |
| Скачивает каталог с `https://discord.com/api/v9/applications/detectable` | Только чтение, без авторизации |
| Компилирует один `.exe` из `lib/Placeholder.cs` через `Add-Type` | `simulator-data\window-placeholder-v4.exe` |
| Создаёт жёсткие ссылки на этот `.exe` | `simulator-data\s\*`, `simulator-data\p\*` |
| Запускает созданные `.exe` на время `-Seconds` | Дочерние процессы текущего пользователя |
| Снимает «метку из интернета» с `.ps1`/`.psm1` проекта | `Unblock-File` в папке проекта |
| Пишет CSV-историю, журналы и кэш каталога | `simulator-data\` |

Скрипт **не** делает следующего: не читает токены Discord, не обращается к
`%APPDATA%\discord`, не меняет реестр, не устанавливает службы, не
запрашивает права администратора, не отправляет ваши данные наружу.

## Известные риски

1. **Ложные срабатывания антивируса.** Сто неподписанных исполняемых файлов с
   именами реальных игр — типичный паттерн для эвристик. С версии 1.1.0
   создаётся один файл и жёсткие ссылки, но срабатывания возможны.
2. **Правила Discord.** Автоматизация ради значка может противоречить условиям
   использования. Ответственность за использование — на пользователе.

## Проверка целостности релиза

В каждом релизе публикуется `SHA256SUMS.txt`. Проверка на Windows PowerShell:

```powershell
Get-FileHash .\Discord.Games.Simulator.<версия>.zip -Algorithm SHA256
```

Хэш должен совпасть со строкой в `SHA256SUMS.txt` из того же релиза.

## Сообщение об уязвимости

Не создавайте публичный issue. Напишите мейнтейнеру через
[GitHub Security Advisory](https://github.com/WinormanTeam/Discord-Games-Simulator/security/advisories/new)
или личным сообщением владельцу репозитория.

Опишите: версию, шаги воспроизведения, потенциальный impact. Ответ — в течение
нескольких дней.
