# Discord-Games-Simulator
Экспериментальная имитация запуска 100 игр для значка «Универсал». Игры скачивать не нужно.

Возможности:
100 игр из официального каталога Discord
Не нужны пароль и токен, в аккаунт скрипт не заходит
Сами игры не скачиваются, создаются только пустые EXE
Панель показывает игру, EXE, PID, таймер, прогресс и запущен ли Discord
История запусков сохраняется в simulator-data/history.csv
Остановить можно через Ctrl+C. Если просто закрыть окно, процессы сами завершатся по таймеру
Исходник открыт, весь код можно прочитать в .ps1

Как пользоваться:
Распакуй архив в любую папку. Start.cmd и Run-Simulator.ps1 должны лежать рядом
Открой десктопный Discord и включи обнаружение игровой активности
Дважды кликни по Start.cmd и выбери режим и запусти тест.
