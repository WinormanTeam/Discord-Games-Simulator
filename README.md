## ✨ Возможности

| Функция | Описание |
| :--- | :--- |
| 🎯 **100 игр в базе** | Имена исполняемых файлов берутся из публичного каталога Discord. |
| 🔒 **Без входа в аккаунт** | Не нужны пароль, токен или QR-код — скрипт **не заходит** в ваш аккаунт. |
| 💾 **Экономия места** | Игры не скачиваются: создаётся один exe-заглушка, остальные — жёсткие ссылки на него. |
| 📊 **Удобная панель** | Текущая игра, имя EXE, PID, таймер, прогресс, ETA и статус Discord. |
| 📝 **Логирование** | История прогонов в `simulator-data/history.csv`, технический журнал в `simulator-data/logs/`. |
| 🛑 **Умное завершение** | `Ctrl+C` в любой момент; при закрытии окна процессы завершатся по таймеру. |
| 🔁 **Дозапуск** | Флаг `-Resume` пропускает игры, которые уже успешно отработали. |
| 🌍 **Два языка** | Интерфейс на русском и английском (`-Language ru|en` или пункт `[L]` в меню). |
| 🔍 **Открытый код** | Весь исходный код — два `.ps1` файла, `.cmd`-лаунчер и C#-исходник заглушки. |

## ⚙️ Требования

| Компонент | Минимум | Зачем |
| :--- | :--- | :--- |
| Windows | 10 / 11 (x64) | WinForms и процессы Windows |
| Windows PowerShell | 5.1 (встроен в Windows) | Скрипт совместим с 5.1; PowerShell 7 тоже работает |
| .NET Framework | 4.5+ | Компиляция exe-заглушки через `Add-Type` |
| Discord | десктопное приложение | Веб-версия не видит локальные процессы |
| Сеть | доступ к `discord.com` | Однократная загрузка каталога (дальше работает кэш) |
| Права | обычный пользователь | Администратор **не** требуется |

> [!NOTE]
> Скрипт **не работает** на Linux и macOS: он запускает Windows-приложения.
> В CI на Linux проверяются только модульные тесты.
>
> [!IMPORTANT]
> Компиляция exe-заглушки (`Add-Type -OutputType`) поддерживается **только
> в Windows PowerShell 5.1**. В PowerShell 7 эта команда недоступна, поэтому
> для работы используйте `Start.cmd` (он вызывает `powershell.exe`).
> В pwsh 7 доступны только `-PrepareOnly` и просмотр каталога.

## 🚀 Как пользоваться

> [!IMPORTANT]
> **Важно:** файлы `Start.cmd`, `Run-Simulator.ps1` и папка `lib` должны лежать рядом!

1. **[Скачай последний релиз](https://github.com/WinormanTeam/Discord-Games-Simulator/releases/latest)** и распакуй архив в любую удобную папку.
2. **Открой десктопный Discord** и убедись, что включено обнаружение игровой активности (*Настройки → Зарегистрированные игры*).
3. **Дважды кликни по `Start.cmd`**, выбери режим в меню и подтверди запуск.
4. Дождись окончания прогона и **проверь значок в Discord вручную** — зачёт не гарантирован.

### Режимы меню

| Пункт | Что делает | Длительность |
| :--- | :--- | :--- |
| `[1]` | Тест: 3 игры × 60 секунд | ~3 мин |
| `[2]` | Полный прогон: 100 игр × 120 секунд | ~3 ч 20 мин |
| `[3]` | Быстрый последовательный: 100 игр × 6 секунд | ~10 мин |
| `[4]` | Параллельный: все окна одновременно | ~2 мин |
| `[5]` | Только подготовка файлов, без запуска | секунды |
| `[L]` | Сменить язык интерфейса | — |

### Параметры командной строки

```powershell
# Тест на трёх играх без вопросов
.\Run-Simulator.ps1 -Count 3 -Seconds 60 -Force

# Быстрый прогон с дозапуском (пропустит уже выполненные игры)
.\Run-Simulator.ps1 -Count 100 -Seconds 6 -Resume -Force

# Все окна одновременно
.\Run-Simulator.ps1 -Parallel -Force

# Только подготовить каталог и заглушки (ничего не запускать)
.\Run-Simulator.ps1 -PrepareOnly

# Английский интерфейс
.\Run-Simulator.ps1 -Menu -Language en
```

| Параметр | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `-Count` | 1..100 | `100` | Сколько игр использовать |
| `-Seconds` | 5..3600 | `120` | Длительность показа каждой игры |
| `-Menu` | switch | — | Интерактивное меню (используется `Start.cmd`) |
| `-Parallel` | switch | — | Запустить все окна одновременно |
| `-PrepareOnly` | switch | — | Только подготовка, без запуска |
| `-Resume` | switch | — | Пропустить игры, выполненные за последние 72 часа |
| `-Force` | switch | — | Не спрашивать подтверждение |
| `-Language` | `ru` / `en` | `ru` | Язык интерфейса (запоминается в `settings.json`) |

## 🩺 Если что-то пошло не так

| Симптом | Причина | Что делать |
| :--- | :--- | :--- |
| `... cannot be loaded because running scripts is disabled` или «файл не имеет цифровой подписи» | Файлы из ZIP помечены как «скачанные из интернета», политика `RemoteSigned` их блокирует | Запускайте через `Start.cmd` (он использует `-ExecutionPolicy Bypass` только для своего процесса). Вручную: `Unblock-File .\Run-Simulator.ps1` |
| `Не удалось получить каталог Discord` / `all attempts failed` | Нет сети, блокировка `discord.com`, прокси или старый TLS | Проверьте доступ к `https://discord.com/api/v9/applications/detectable`; повторный запуск использует кэш `simulator-data\catalog\detectable.json` |
| `No compatible executable names found` | Каталог изменился или все имена отфильтрованы | Запустите `-PrepareOnly` и посмотрите `simulator-data\selected-games.csv`; удалите кэш каталога, чтобы обновить список |
| Антивирус удаляет `.exe` из `simulator-data` | Сто одинаковых неподписанных exe с именами игр похожи на вредоносное поведение | Добавьте папку в исключения **на свой риск**; теперь создаётся один файл и жёсткие ссылки, но ложные срабатывания возможны |
| Discord не показывает игру | Discord не считает процесс игрой, окно слишком короткое или клиент не обновил активность | Увеличьте `-Seconds` (30–120), откройте «Зарегистрированные игры», проверьте вручную |
| `Another simulator instance is already running` | Уже запущен второй экземпляр | Закройте первое окно симулятора |
| Прогон прерван на середине | Закрыли окно / Ctrl+C / сон компьютера | Запустите с `-Resume`: выполненные игры будут пропущены |

Технический журнал каждого запуска: `simulator-data\logs\run-<дата>.log`.

## ⚠️ Ограничения и риски (прочитайте)

- **Значок не гарантирован.** Discord определяет активность по эвристикам; имитация запуска может не засчитываться.
- Скрипт **создаёт и запускает локальные исполняемые файлы** (один скомпилированный из C# и жёсткие ссылки на него). Это может вызывать **ложные срабатывания антивируса**. Запускайте только из этого репозитория и сверяйте хэш релиза (`SHA256SUMS.txt`).
- Автоматическая накрутка активности может противоречить правилам Discord. **Используйте на свой риск**; возможны ограничения аккаунта.
- Один прогон 100 игр × 120 секунд занимает **более трёх часов**; компьютер не должен уходить в сон.
- Скрипт не «взламывает» ничего и не обходит защиту: он просто запускает процессы с определёнными именами.

## 🗂️ Что создаётся на диске

```
simulator-data/
├─ window-placeholder-v4.exe   # один скомпилированный exe-заглушка
├─ history.csv                 # история прогонов (time, game, executable, status, mode)
├─ selected-games.csv          # список отобранных игр
├─ settings.json               # выбранный язык интерфейса
├─ catalog/detectable.json     # кэш каталога Discord
├─ logs/run-*.log              # технический журнал
├─ s/0..99/                    # экземпляры заглушек (жёсткие ссылки)
└─ p/0..99/                    # то же для параллельного режима
```

**Как удалить всё:** закройте симулятор и удалите папку `simulator-data`. Больше ничего в системе скрипт не меняет (кроме временной метки «из интернета», снимаемой через `Unblock-File`).

## 🧑‍💻 Разработка

```powershell
# Модульные тесты (работают и на Linux)
Install-Module Pester -MinimumVersion 5.5 -Scope CurrentUser
Invoke-Pester -Path ./tests

# Статический анализ
Install-Module PSScriptAnalyzer -Scope CurrentUser
Invoke-ScriptAnalyzer -Path . -Recurse -Settings ./PSScriptAnalyzerSettings.psd1
```

Структура проекта:

| Путь | Назначение |
| :--- | :--- |
| `Start.cmd` | Лаунчер: `-ExecutionPolicy Bypass`, UTF-8, проброс аргументов |
| `Run-Simulator.ps1` | Точка входа: меню, каталог, запуск, панель, журнал |
| `lib/SimulatorCore.ps1` | Чистые функции: отбор игр, безопасность путей, форматирование (покрыты тестами) |
| `lib/Placeholder.cs` | Исходник exe-заглушки (коды возврата 0/2/3) |
| `tests/SimulatorCore.Tests.ps1` | Pester-тесты |
| `tools/Build-Release.ps1` | Сборка ZIP релиза и `SHA256SUMS.txt` |
| `.github/workflows/analyze.yml` | CI: Pester, PSScriptAnalyzer, парсер, smoke-тест |

Ветки и PR — через `CONTRIBUTING.md`. Ломающие изменения — только с обновлением тестов.
